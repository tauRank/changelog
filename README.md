# tauRank changelog

Product updates for [tauRank](https://taurank.com), a rank tracker for Airbnb and Booking.com listings. It searches
daily from the countries your guests come from, shows where your listing ranks in each and the gap
between them, and compares your price with similar listings.

- [CHANGELOG.md](CHANGELOG.md): every update, newest first
- [Releases](https://github.com/tauRank/changelog/releases): one per update
- [taurank.com/changelog](https://taurank.com/changelog), with an [Atom feed](https://taurank.com/changelog.xml)

This repository holds the changelog only; it is published from the product and edits here are overwritten.
